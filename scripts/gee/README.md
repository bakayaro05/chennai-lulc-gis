# Curated Google Earth Engine scripts

This directory has **62 selected source copies** from the unchanged 156-file historical Earth Engine archive. Every copied `.js` file is checked against the original SHA-256. No source logic is rewritten.

**Start with [INDEX.md](INDEX.md) and [EXECUTION_ORDER.md](EXECUTION_ORDER.md)**.

The collection includes original baseline sources, read-only QA, derived four-class reporting, retained post-classification candidates, a 2010 sensitivity experiment, external-region benchmarks, and visualization exports. These roles are **not interchangeable**. No script has been rerun on GEE as part of this curation.
